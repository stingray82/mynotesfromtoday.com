Need it so build it

A welcome note about the ideas, experiments and half-finished thoughts that belong here.

November 1, 2026

I have been building more and more chrome Extension to make my life easier including the one that generates the links in this article and also the one it is about this blog is hosted on Bunny.net and one of the issues I have every time I push an update is I have to login or run a cli command to clear the cache.

I didn't want to do this anymore so I built a quick and dirty chrome Extension to do that for me for any number of sites I can clear from the browser, clear while the site is on a page by using a short cut you can view it here https://wlink.uk/os7m7g/

It's still only a version 1.0.0 and its only been lightly tested but its another problem that will hopefully be no more.
